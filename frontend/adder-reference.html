Binary Adders, Subtractors & 4-Bit Parallel Adder (IC 7483)

Binary adders and subtractors are the foundational arithmetic circuits of modern computers, microprocessors, and ALUs. They perform fundamental binary addition and 2's complement subtraction across single-bit and multi-bit words.

1. Half Adder & Half Subtractor

A Half Adder and a Half Subtractor operate on two single-bit binary inputs without considering an incoming carry or borrow from a prior stage.

2. Full Adder (3-Input Binary Addition)

A Full Adder adds three 1-bit binary inputs: two data operands A and B, plus an incoming carry bit C_in from a previous lower column.

Full Adder Truth Table (8 Combinations)

000000 + 0 + 0 = 0
001100 + 0 + 1 = 1
010100 + 1 + 0 = 1
011010 + 1 + 1 = 2 (Binary 10₂)
100101 + 0 + 0 = 1
101011 + 0 + 1 = 2 (Binary 10₂)

3. 4-Bit Binary Parallel Adder / Subtractor (IC 7483)

The IC 7483 / 74LS83 is a monolithic 4-bit parallel binary full adder. By combining the 7483 with 4 external XOR gates, the circuit functions as a versatile combined Adder and Subtractor controlled by a single Mode line (M).

IC 7483 Hardware Pinout (DIP-16)

              IC 7483 DIP-16
               .-----\_/-----.
   (Bit 4)  A4 | 1        16 | B4 (Bit 4)
   (Sum 3)  S3 | 2        15 | S4 (Sum 4 - MSB)
   (Bit 3)  A3 | 3        14 | C4 (Carry Out)
   (Bit 3)  B3 | 4        13 | C0 (Carry In)
   (Power) VCC | 5        12 | GND (Ground 0V)
   (Sum 2)  S2 | 6        11 | B1 (Bit 1)
   (Bit 2)  B2 | 7        10 | A1 (Bit 1)
   (Bit 2)  A2 | 8         9 | S1 (Sum 1 - LSB)
               '-------------'

XOR Gate Controlled Inversion Principle

An XOR gate functions as a programmable controlled inverter:
• When Mode M = 0: B ⊕ 0 = B (Pass-through uncomplemented)
• When Mode M = 1: B ⊕ 1 = B̅ (1's complement bit inversion)

Addition Mode (M = 0):
• Mode M = 0 sets Carry-In C₀ = 0.
• B inputs pass through unchanged.
• Result = A + B + 0 = A + B
Subtraction Mode (M = 1):
• Mode M = 1 sets Carry-In C₀ = 1 (+1 for 2's complement).
• B inputs are bit-wise inverted to B̅.
• Result = A + B̅ + 1 = A − B (2's complement subtraction!)

4. Worked Step-by-Step Examples

Example 1 4-Bit Binary Addition (Mode M = 0)

Compute A + B where A = 0110₂ (6₁₀) and B = 0101₂ (5₁₀):

  • Bit 1: A₁=0, B₁=0, C₀=0 → S₁ = 1, C₁ = 0
  • Bit 2: A₂=1, B₂=0, C₁=0 → S₂ = 1, C₂ = 0
  • Bit 3: A₃=1, B₃=1, C₂=0 → S₃ = 0, C₃ = 1
  • Bit 4: A₄=0, B₄=0, C₃=1 → S₄ = 1, C₄ = 0
  • Final Sum: (S₄ S₃ S₂ S₁) = 1011₂ = 11₁₀ (Exact sum: 6 + 5 = 11).

Example 2 2's Complement Subtraction (Mode M = 1)

Compute A − B where A = 1001₂ (9₁₀) and B = 0100₂ (4₁₀):

  • Step 1: XOR gates invert B: B = 0100₂ → B̅ = 1011₂.
  • Step 2: Mode M = 1 injects initial carry C₀ = 1.
  • Step 3: Add A + B̅ + C₀: 1001₂ + 1011₂ + 1 = 1 0101₂.
  • Carry Out C₄ = 1 indicates a positive result with no borrow!
  • Final Difference: (S₄ S₃ S₂ S₁) = 0101₂ = 5₁₀ (Exact: 9 − 4 = 5).

5. Applications of Digital Adders

1. CPU ALUs & Math Coprocessors

Forms the fundamental arithmetic heart of ALUs to calculate additions, subtractions, memory addresses, and pointer offsets.

2. Digital Signal Processing (DSP)

Powers high-speed Multiply-Accumulate (MAC) units for digital filtering, audio mixing, and image transforms (FFT/DCT).

3. Program Counter Incrementation

Used to increment instruction program counters (PC) on every microprocessor machine fetch cycle.
