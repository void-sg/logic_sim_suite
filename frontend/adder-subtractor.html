THEORY & IMPLEMENTATION

Adder / Subtractor Architecture (IC 74LS83)

The 2's Complement Hardware Sharing Trick

In computer arithmetic, subtraction is executed using the exact same adder hardware by leveraging two's complement:

A - B = A + (2's complement of B) = A + (B' + 1)

By feeding the mode bit M into an XOR gate with each bit of B, and also connecting M directly to the initial carry-in Cin:

  • When M = 0 (Addition): B ⊕ 0 = B (bits unchanged), and Cin = 0. Output is A + B.
  • When M = 1 (Subtraction): B ⊕ 1 = B' (bitwise NOT / 1's complement), and Cin = 1 (+1). Output is A + B' + 1 = A - B.

Full Adder Boolean Equations

Sum (Si) = Ai ⊕ Bi ⊕ Cin
Carry-Out (Cout) = (Ai · Bi) + (Cin · (Ai ⊕ Bi))

IC 74LS83 Features

• 4-Bit Binary Full Adder with Fast Lookahead Carry generation.
• Cascading: Connect C4 (Cout) of low-order stage into C0 (Cin) of high-order stage for 8-bit or 16-bit operations.
• Subtraction Carry/Borrow rule: Cout = 1 indicates positive result (no borrow needed), while Cout = 0 indicates a borrow occurred (result is negative in 2's complement).
