CODE CONVERSION

Code Converters - BCD to/from Excess-3 Code

BCD (Binary Coded Decimal) and Excess-3 are numeric representations used in digital arithmetic circuits. This guide details truth tables, K-map simplifications using don't-care conditions (X), minimized logic expressions, and circuit designs.

1. Overview of BCD and Excess-3 Codes

What is BCD (8421 Code)?

Binary Coded Decimal (BCD) represents decimal digits 0 through 9 using 4-bit binary values (0000 to 1001). Bit combinations from 1010 to 1111 (10 to 15) are invalid in BCD and treated as don't-care conditions (X) in K-maps.

What is Excess-3 Code?

Excess-3 is an unweighted, self-complementing code derived by adding 3 (0011 in binary) to each decimal digit's BCD representation. Self-complementing means taking the 1's complement of an Excess-3 code yields the 9's complement of the corresponding decimal digit.

Key Characteristics:

Unweighted Code Self-Complementing Don't-Care States (10–15 in BCD)

Minimized Boolean Expressions

  • E0 (z) = B0'
  • E1 (y) = B1 B0 + B1' B0' = (B1 ⊕ B0)'
  • E2 (x) = B2' B1 + B2' B0 + B2 B1' B0' = B2 ⊕ (B1 + B0)
  • E3 (w) = B3 + B2 B1 + B2 B0 = B3 + B2(B1 + B0)

3. Converting Excess-3 to BCD Code

Reverse conversion processes 4-bit Excess-3 inputs (E3, E2, E1, E0) to produce BCD outputs (B3, B2, B1, B0). Excess-3 input states 0000, 0001, 0010 (0 to 2) and 1101, 1110, 1111 (13 to 15) are invalid states, marked as don't-care conditions (X).

4. Applications of BCD and Excess-3 Converters

  • Decimal Arithmetic Units: Simplifies 9's complement subtraction algorithms in digital calculators and financial computing hardware.
  • Seven-Segment Display Controllers: Facilitates digital display driving where decimal inputs must be encoded into self-complementing logic formats.
  • Legacy Computing & Counters: Used in multi-digit decimal counters and early electronic data processing systems.
