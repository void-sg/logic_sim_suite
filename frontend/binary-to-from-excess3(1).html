FORWARD CONVERSION

BCD to Gray Code Converter

Conversion Principle & Truth Table

BCD code represents decimal digits (0–9) using 4 bits (B₃B₂B₁B₀). States 1010 to 1111 (10 to 15) are invalid in BCD and treated as Don't Care conditions (X) during K-map simplification.

Simplified Logic Expressions

Minimizing minterms with Don't Care states (10–15) via K-maps yields:

  • G₃ = B₃
  • G₂ = B₃ + B₂
  • G₁ = B₂ ⊕ B₁
  • G₀ = B₁ ⊕ B₀

02

REVERSE CONVERSION

Gray Code to BCD Converter

Conversion Logic

Reverse conversion takes 4-bit Gray code inputs (G₃G₂G₁G₀) and converts them back to valid BCD outputs (B₃B₂B₁B₀).

Simplified Expressions

  • B₃ = G₃
  • B₂ = G₃ ⊕ G₂
  • B₁ = G₃ ⊕ G₂ ⊕ G₁ = B₂ ⊕ G₁
  • B₀ = G₃ ⊕ G₂ ⊕ G₁ ⊕ G₀ = B₁ ⊕ G₀
Hardware Design Note The circuit is constructed using standard XOR gates for bits 0, 1, and 2, and an OR gate for bit 2 in forward conversion due to don't-care optimization.
