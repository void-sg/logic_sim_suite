THEORY & EQUATIONS

Magnitude Comparator Architecture (IC 74LS85)

MSB-Priority Logic

Binary magnitude comparison evaluates bits starting strictly from the Most Significant Bit (MSB, Bit 3) down to the LSB (Bit 0). The first pair of bits where \(A_i \neq B_i\) conclusively establishes the inequality, rendering all lower-order bits irrelevant.

74LS85 Boolean Logic Equations

EQi = Ai XNOR Bi = (Ai·Bi) + (Ai'·Bi')

A > B = (A3·B3') + (EQ3·A2·B2') + (EQ3·EQ2·A1·B1') + (EQ3·EQ2·EQ1·A0·B0')
A < B = (A3'·B3) + (EQ3·A2'·B2) + (EQ3·EQ2·A1'·B1) + (EQ3·EQ2·EQ1·A0'·B0)
A = B = EQ3 · EQ2 · EQ1 · EQ0

Multi-Stage Cascading (8-Bit / 12-Bit Expansion)

To compare words larger than 4 bits, multiple IC 74LS85s are chained together. The outputs of the less significant stage connect directly to the cascade inputs of the next higher stage:

OA>B = (A > B) + ((A = B) · IA>B)
OA<B = (A < B) + ((A = B) · IA<B)
OA=B = (A = B) · IA=B

IC 74LS85 Standalone Tie-Off

When used as a standalone single-stage 4-bit comparator (no lower-order stage), the datasheet specifies:

IA > B = 0
IA < B = 0
IA = B = 1 (Tied HIGH)

This ensures that if all 4 bits match, the IC correctly concludes \(A = B\).
