Converter

Multiplexer

03

MAGNITUDE COMPARISON

Comparator

Topics Covered

  • n-bit Magnitude Comparator Comparison of two n-bit binary numbers A and B, producing A > B, A = B, and A < B outputs.
  • Truth Table and Logic Circuit Truth table, SOP/POS expression, K-map simplification, and logic-gate design for a selected bit size.
  • MSB Priority in Comparison The first unequal bit, starting from the most significant bit, determines the final comparison output.
  • n-bit Comparator Using 4-bit Comparator Construction of a larger comparator by cascading 4-bit comparator blocks through expansion inputs.
  • IC 74LS85 Implementation 4-bit magnitude comparator IC, pinout details, and cascading method for larger binary numbers.

BINARY ARITHMETIC

Adder

Topics Covered

  • n-bit Binary Adder Addition of two n-bit binary numbers with sum and carry propagation between each stage.
  • Full Adder as a Basic Block Full adder inputs are A, B, and carry input Cin. Outputs are Sum and carry output Cout.
  • n-bit Adder Using Full Adders Realisation of an n-bit ripple-carry or parallel adder by cascading n full-adder blocks.
  • n-bit Adder-Subtractor Addition and subtraction using XOR gates and two's complement arithmetic with a mode-control input.
  • BCD Adder BCD addition with correction logic when output exceeds 1001 or generates a carry.
  • IC 74LS83 Implementation 4-bit binary adder IC, pin diagram, carry logic, and use as a building block for larger adders.
