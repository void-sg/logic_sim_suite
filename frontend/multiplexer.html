Multiplexer Architecture (IC 74LS153)

The 8:1 MUX from IC 74LS153 (Dual 4:1)

The IC 74LS153 contains two independent 4:1 multiplexers that share common select lines (A and B), each having its own active-low strobe pin (\(\bar{1G}\) and \(\bar{2G}\)).

To form an 8:1 multiplexer without extra control logic:

  • Inputs D0–D3 connect to Section 1 (\(1C0–1C3\)).
  • Inputs D4–D7 connect to Section 2 (\(2C0–2C3\)).
  • Select lines S1, S0 connect to the shared select inputs.
  • S2 drives the section enable pins: Section 1 is enabled when \(S_2 = 0\), and Section 2 is enabled when \(S_2 = 1\).
  • The outputs are combined with an OR gate: \(Y = 1Y + 2Y\).

Boolean Expression for 8:1 MUX

Y = S2'S1'S0'·D0 + S2'S1'S0·D1 + S2'S1S0'·D2 + S2'S1S0·D3 +
    S2·S1'S0'·D4 + S2·S1'S0·D5 + S2·S1S0'·D6 + S2·S1S0·D7

Select Line Rule

For any \(n\)-input multiplexer, the number of select lines \(m\) required is:

m = log₂(n)
• 2 : 1 MUX → 1 select line
• 4 : 1 MUX → 2 select lines
• 8 : 1 MUX → 3 select lines
• 16: 1 MUX → 4 select lines
