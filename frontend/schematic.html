Circuit Stage Logic & Interconnect Breakdown

1. Section Steering (74LS04)
Inverts MSB select line S2 = 0 to drive active-low enables 1G and 2G.
2. Shared Select Bus
Address lines S1 and S0 drive inputs B and A on both 74LS153 sections: B = 0, A = 0.
3. Unit U2A (Channels D0-D3)
Section 1 output: 1Y = 0. Active when S2 = 0 and ~G = 0.
4. Unit U2B (Channels D4-D7)
Section 2 output: 2Y = 0. Active when S2 = 1 and ~G = 0.
5. Combining OR Gate (74LS32)
Combined output: Y = 1Y OR 2Y = 0. Transmits the active section to output port Y.
