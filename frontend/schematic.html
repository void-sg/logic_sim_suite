8:1 Multiplexer Architecture (Dual IC 74LS153 Sections + Inverter + OR)

1. Section Steering
Inverter U1 (74LS04) inverts MSB S₂ to steer active-low strobes: Section 1 enabled when S₂=0, Section 2 enabled when S₂=1.
2. Shared Select Bus
Lines S₁ and S₀ route to shared inputs B and A on both dual 74LS153 sections simultaneously.
3. OR Gate Combining
U3 (74LS32) combines section outputs (1Y OR 2Y). Disabled section is held at 0, passing only the selected channel to Y.

4:1 Multiplexer Architecture (Single IC 74LS153 Section)

1. Data Selection
Select lines B (S₁) and A (S₀) decode one of the four data lines (1C₀..1C₃) using internal AND-OR gating.
2. Active-Low Strobe (~1G)
When ~1G = 0, the multiplexer is enabled. When ~1G = 1, output 1Y is forced to 0 regardless of data or select lines.

4-Bit Magnitude Comparator Architecture (IC 74LS85)

1. MSB Priority
Bits are compared from A₃/B₃ (MSB) down to A₀/B₀ (LSB). The first mismatched bit pair decisively determines inequality.
2. Cascade Expansion
If all 4 bits are equal, the decision falls through to cascade inputs (IA>B, IA=B, IA<B) for modular multi-chip chaining.

4-Bit Binary Adder / Subtractor Architecture (IC 74LS83 + 74LS86)

1. 2's Complement Trick
When M=0, B bits pass through XOR gates unchanged and C₀=0 (Addition: A + B). When M=1, B bits are inverted and C₀=1 (Subtraction: A + B' + 1 = A − B).
2. Carry-Out & Borrow Flag
For addition, C₄ is the carry-out (overflow). For subtraction, C₄=1 indicates no borrow (positive result); C₄=0 indicates a borrow occurred.
